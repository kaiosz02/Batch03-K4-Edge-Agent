## Hướng dẫn chạy
1. Đảm bảo đã cài đặt Python và Node.js.
2. Cài đặt các thư viện/phụ thuộc cho cả frontend và backend.
3. Chạy backend bằng lệnh phù hợp (ví dụ: `npm run backend` hoặc `python main.py`).
4. Chạy frontend (ví dụ: `npm start`).
